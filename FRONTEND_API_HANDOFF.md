# VibezLink Backend API Reference

This document was generated by reading the NestJS backend controllers and entities in this project.
It is meant for frontend integration and for mapping each endpoint back to the underlying table/entity.

## Base URLs

Production:

```txt
https://vibezlink-app-on-god-backend-production.up.railway.app
```

Local:

```txt
http://localhost:3000
```

Swagger UI:

```txt
https://vibezlink-app-on-god-backend-production.up.railway.app/api-docs
```

OpenAPI JSON:

```txt
https://vibezlink-app-on-god-backend-production.up.railway.app/api-docs-json
```

Frontend env example:

```env
VITE_API_BASE_URL=https://vibezlink-app-on-god-backend-production.up.railway.app
```

Protected endpoints require:

```http
Authorization: Bearer <access_token>
Content-Type: application/json
Accept: application/json
```

## Global Request / Response Pattern

Most write endpoints accept JSON bodies.
Most list endpoints accept query filters and return an object with:

```json
{
  "items": [],
  "total": 0,
  "meta": {}
}
```

The exact shape differs per controller. Swagger is the final source of truth for field-level examples.
